# Naver API 기반 쇼핑 트렌드 분석 대시보드 구축 작업지시서

이 문서는 네이버 검색 및 쇼핑 API 데이터를 활용하여 트렌드를 시각화하고 심층적인 데이터 분석(EDA)을 제공하는 Streamlit 대시보드 구축에 대한 요구사항과 설계 사양을 정의합니다.

## 1. 프로젝트 개요
- **목적**: 검색어 트렌드 비교 및 관련 상품/콘텐츠 분석을 통한 통찰력 확보
- **도구**: 
  - **Framework**: Streamlit
  - **Visualization**: Plotly (Express & Graph Objects)
  - **Data Processing**: Pandas
  - **API**: Naver Search API (Datalab, Shop, Blog)

## 2. 주요 기능 요구사항

### 2.1 검색 및 조회 설정 (사이드바)
- **키워드 입력**: 다중 키워드를 쉼표(`,`)로 구분하여 입력받아 트렌드 비교 가능하게 함.
- **기간 설정**: 분석을 수행할 데이터의 시작일과 종료일을 선택 가능하게 함.
- **실행 제어**: 분석 실행 버튼을 통해 API 요청 및 시각화 프로세스 트리거.

### 2.2 대시보드 레이아웃 및 메뉴 구성 (탭 구조)
대시보드는 다음의 4가지 주요 탭으로 구성함.

1. **📈 트렌드 분석**: 검색어 간의 시계열 추이 및 요일별 패턴 비교
2. **🛒 쇼핑 EDA**: 검색어 관련 상품의 가격 분포, 브랜드 점유율, 판매처 분석
3. **📝 콘텐츠 통계**: 블로그 등 관련 콘텐츠의 작성 추이 및 최신 정보
4. **🗂️ Raw Data**: 분석에 사용된 원본 데이터를 표 형식으로 제공 및 다운로드 기능

## 3. 상세 구현 항목 (시각화 및 데이터 요약)

### 3.1 시각화 그래프 (5가지 이상)
1. **일별 검색 트렌드 (Line Chart)**: 키워드별 검색량 변화를 시계열로 비교.
2. **요일별 검색 강도 (Density Heatmap)**: 요일별 평균 검색 비율을 히트맵으로 시각화.
3. **상품 가격 분포 (Histogram)**: 키워드별 상품 가격대의 분포와 중첩 분석.
4. **주요 판매처 빈도 (Bar Chart)**: 상품이 등록된 주요 쇼핑몰(Mall) 별 비중 분석.
5. **브랜드별 가격 분포 (Scatter Plot)**: 브랜드와 가격 간의 관계 및 상품 집중도 분석.
6. **브랜드 점유율 (Horizontal Bar Chart)**: 상위 브랜드별 상품 수 비교.
7. **카테고리 분포 (Pie Chart)**: 쇼핑 카테고리별 상품 비중 시각화.
8. **블로그 작성 추이 (Histogram)**: 날짜별 콘텐츠 생산 활동성 분석.

### 3.2 요약 및 분석 표 (5가지 이상)
1. **키워드별 검색 통계 요약**: 평균, 최대, 최소 검색 지수 산출.
2. **검색 피크 발생일 분석**: 각 키워드별 최고 검색량을 기록한 날짜와 지수.
3. **상품 가격 통계**: 키워드별 평균가, 중앙값, 최저/최고가 및 수집된 상품 수.
4. **상위 검색 상품 리스트**: 상품명, 가격, 판매처, 브랜드 정보를 포함한 상세 목록.
5. **블로그 콘텐츠 요약**: 키워드별 수집된 게시물 수 및 통계.
6. **최신 콘텐츠 헤드라인**: 제목, 작성일, 링크를 포함한 최신 블로그 목록.

## 4. 데이터 연동 및 보안
- **환경 변수**: API Client ID 및 Secret은 `.env` 파일을 통해 로드하고 코드 내 직접 노출을 금지함.
- **예외 처리**: API 호출 실패나 데이터 부재 시 사용자에게 적절한 안내 메시지(Error/Info) 표시.
- **다운로드**: 분석 결과물을 사용자가 CSV 파일로 내보낼 수 있는 기능 제공.
