# Coffee Index Analysis Methodology

본 문서는 서울시 주요 14개 상권을 대상으로 'Coffee Index (카페 창업 적합도 지수)'를 산출하기 위한 종합 분석 방법론을 설명합니다. 기존 분석에서 다루어진 "수익 및 리스크" 요인과 더불어 최신 네이버 검색어 트렌드 "Trend Index"를 새롭게 융합하여 도출하였습니다.

## 1. 분석 개요
- **목표**: 높은 수요(매출, 유동인구)와 긍정적인 검색 트렌드를 가지면서도, 리스크(임대료, 공실률, 점포경쟁)가 낮은 **'숨겨진 꿀상권(Hidden Gem)'** 탐색.
- **분석 지역**: 사전 분석을 통해 필터링된 서울 시내 14개 주요 상권 (양재역, 성신여대, 구로디지털단지역 등)

## 2. 사용 데이터 원본 (Data Sources)
본 분석은 6가지 이종 지표 데이터를 결합하여 완성되었습니다.

1. **상권분석서비스 (추정매출)**: 상권별 카페/커피(CS100010) 업종의 분기별 실결제 규모
2. **상권분석서비스 (길단위인구)**: 상권별 유동인구 총합
3. **Naver DataLab API (Trend Index)**: 해당 상권의 온라인 검색 관심도 증가율 및 점유율(주 단위/월 단위 변동)
4. **상권분석서비스 (점포수)**: 상권별 커피 업판 점포 수 (경쟁 강도)
5. **소규모/중대형 상가 임대가격지수**: 분기별 임대료 증감률 (고정 비용 부담 수준)
6. **소규모/중대형 상가 공실률**: 분기별 공실 발생 수준 (상권 쇠퇴도 및 활력 지표)

## 3. Coffee Index 산출 로직 설계

### 3.1 지표 정규화 (Min-Max Scaling)
단위가 각기 다른 6개 지표를 상호 비교하기 위하여, 각 지표별로 가장 최근 4분기(1년) 데이터를 평균낸 뒤 `0 ~ 100` 스케일로 정규화(Min-Max Scaling) 하였습니다.
$ Scaled\_Value = \left( \frac{Value - Min}{Max - Min} \right) \times 100 $

### 3.2 평가 요소의 가중치 할당
창업자 관점에서 수익 확보에 기여하는 '가점 지표(Positive Factors)'와 부담이 되는 '감점 지표(Negative Factors)'로 나누어 가중합을 산출하였습니다.

**[가점 지표: 수익 및 성장 기대성]**
* **추정 매출 (25%)**: 실제 소비 시장의 크기
* **유동 인구 (20%)**: 잠재 고객 규모 및 접근성
* **Trend Index (15%)**: 온라인 검색량 기반의 핫플레이스 "화제성" 및 "성장세"

**[감점 지표: 고정 비용 및 경쟁 심화도]**
* **임대 지수 (15%)**: 월 고정 임대료 부담도
* **점포 수 (15%)**: 동종 업계 진입 장벽 및 경쟁 과도화
* **공실률 (10%)**: 주변 상가 빈 점포로 인한 상권 위축 우려

### 3.3 최종 Coffee Index 공식
```text
Positive_Factors = (Sales_Score * 0.25) + (Pop_Score * 0.20) + (Trend_Score * 0.15)
Negative_Factors = (Rent_Score * 0.15) + (Store_Score * 0.15) + (Vacancy_Score * 0.10)

Coffee_Index_Raw = Positive_Factors - Negative_Factors
```
산출된 `Coffee_Index_Raw` 값을 직관적으로 판단할 수 있도록 다시 한 번 `0 ~ 100` 스케일로 변환하여 최종 **Coffee Index**를 도출하였습니다. 값이 100에 가까울수록 "고수익, 저위험" 형태의 가장 유망한 상권임을 의미합니다.
