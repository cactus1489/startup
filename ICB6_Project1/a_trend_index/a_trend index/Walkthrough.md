# 🚶‍♂️ 서울시 카페 창업 분석 프로젝트 Walkthrough (v0.5)

본 문서는 `20260214` 폴더 내의 분석 프로세스 및 결과물 활용 방법을 안내합니다.

---

## 1. 개요
본 프로젝트는 서울시 공공데이터와 네이버 검색 트렌드 데이터를 결합하여, **시계열 중심의 카페 창업 적합 상권**을 도출하는 전문가용 분석 시스템입니다. v0.5에서는 지리적 분석 도구가 대폭 강화되었습니다.

---

## 2. 주요 도구 및 파일 구성
- **📊 대시보드 (`dashboard_v0.5.html`)**: 분석 결과를 시각화하고 지리적 필터링을 제공하는 메인 결과물입니다.
- **🗺️ 지리 데이터 (`data/dashboard_geo_data.json`)**: 자치구 순위, 상권 좌표, 브랜드별 매장 위치 정보가 포함된 핵심 데이터셋입니다.
- **🛠️ 데이터 추출 도구 (`extract_coffee_data.py`)**: 53만 건의 소상공인 데이터를 분석하여 2만 6천 개의 카페 브랜드를 분류 및 정제합니다.
- **📄 전처리 리포트 (`data_preprocessing_report_v0.4.md`)**: 데이터 정제 과정과 통계적 근거를 상세히 설명한 문서입니다.

---

## 3. 핵심 분석 방법론
1.  **지리적 계층 필터 (Hierarchical Filter)**: 자치구(적합도 순) → 세부 상권(Top 50) → 브랜드별 필터링을 통해 타겟 지역을 정밀하게 탐색합니다.
2.  **브랜드 클러스터링**: 주요 프랜차이즈(스타벅스, 메가커피 등)와 개인 카페의 분포를 상권 적합도 지수와 결합하여 경쟁 강도를 시각화합니다.
3.  **Top N 시각화**: 슬라이더를 통해 노출할 상위 상권의 범위를 실시간으로 제어하며 광역 트렌드와 국지적 트렌드를 동시에 비교합니다.
