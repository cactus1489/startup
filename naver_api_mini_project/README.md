# Naver API Mini Project - K-디저트 트렌드 분석

이 프로젝트는 네이버의 쇼핑인사이트, 블로그 검색, 쇼핑 상품 검색 API를 활용하여 최신 K-디저트(두바이 초콜릿, 두쫀쿠로 등)의 소비 패턴과 트렌드를 분석하는 미니 프로젝트입니다.

## 주요 기능
- **쇼핑 트렌드 수집**: 식품 카테고리 내 특정 키워드의 클릭 지수 수집.
- **콘텐츠 분석**: 블로그 검색 결과를 통한 사용자 반응 및 리뷰 수집.
- **상품 데이터 수집**: 실제 네이버 쇼핑에 등록된 상품 리스트 및 가격 정보 수집.
- **자동 파일 저장**: 수집된 데이터를 `{API}_{내용}_{날짜}.csv` 형식으로 자동 저장.

## 프로젝트 구조
- `doc/`: API 개발 가이드 마크다운 파일.
- `data/`: 수집된 CSV 데이터가 저장되는 폴더.
- `collect_data.py`: 데이터 수집 메인 파이썬 스크립트.
- `.env`: 네이버 API 클라이언트 정보 (본인 정보로 수정 필요).

## 실행 방법
1. `.env` 파일에 네이버 개발자 센터에서 발급받은 `CLIENT_ID`와 `CLIENT_SECRET`을 입력합니다.
2. 가상환경이 활성화된 상태에서 아래 명령어를 실행합니다.
   ```bash
   python collect_data.py
   ```
3. `data/` 폴더 내에 생성된 CSV 파일들을 확인합니다.
