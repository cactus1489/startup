# Streamlit 대시보드 구축 작업지시서

이 문서는 `naver_api_mini_project`를 통해 수집된 데이터를 시각화하고 분석하기 위한 Streamlit 대시보드 개발 가이드라인입니다.

## 1. 프로젝트 개요
- **목적**: 수집된 K-디저트(두바이 초콜릿, 두쫀쿠로 등)의 쇼핑 트렌드와 검색 데이터를 시각적으로 분석.
- **주요 도구**: Streamlit (프레임워크), Plotly (시각화 라이브러리), Pandas (데이터 처리).

## 2. 핵심 요구사항
### 2.1 시각화 및 인터랙션
- **Plotly 활용**: 모든 그래프는 인터랙티브한 Plotly 라이브러리를 사용하여 구현.
- **키워드 비교**: 사용자가 입력하거나 선택한 키워드들을 실시간으로 비교 분석할 수 있어야 함.
- **실시간 API 연동**: 로컬 CSV뿐만 아니라 실시간 API 호출 결과를 즉시 반영할 수 있는 구조 지향.

### 2.2 UI/UX 구조
- **탭(Tabs) 및 메뉴 구성**: 논리적인 데이터 흐름에 따라 최소 4개 이상의 탭으로 구성.
  - 예: 📈 트랜드 분석, 🛒 쇼핑 데이터, 📝 블로그/콘텐츠, 🗂️ 원본 데이터 등.
- **사이드바**: 카테고리 선택, 키워드 입력, 기간 설정 등의 제어판 배치.

### 2.3 데이터 분석(EDA) 필수 항목
대시보드는 최소 **5가지 이상의 표(Table)**와 **5가지 이상의 그래프(Graph)**를 포함해야 합니다.

#### [추천 그래프 리스트]
1. **시계열 라인 차트**: 날짜별 클릭 지수 트렌드 비교.
2. **바 차트**: 키워드별 평균 클릭 지수 또는 검색량 비교.
3. **파이/도넛 차트**: 기기별(PC/Mobile) 또는 성별 클릭 비중.
4. **산점도(Scatter)**: 특정 지표 간의 상관관계 분석.
5. **히트맵(Heatmap)**: 요일별/시간별 트렌드 집중도 분석.

#### [추천 표(Table) 리스트]
1. **요약 통계표**: 키워드별 총 클릭수, 평균, 최대값 등을 정리한 표.
2. **쇼핑 상품 리스트**: 가격대별, 몰별 상위 상품 정보 표.
3. **블로그 콘텐츠 리스트**: 주요 제목 및 링크 정보 표.
4. **변동률 분석표**: 전일 대비 또는 전주 대비 트렌드 변화율 표.
5. **데이터 미리보기**: 수집된 원본 데이터(Raw Data) 확인용 표.

## 3. 기술적 환경 설정
- **가상환경**: `.venv` 사용 권장.
- **의존성 관리**: `requirements.txt`에 사용된 모든 라이브러리 명시.
- **보안**: `.env` 파일을 통한 API Key 관리 및 `.gitignore` 설정 철저.

## 4. 최종 결과물 목표
사용자가 키워드를 입력했을 때, 해당 키워드가 시장에서 어떤 위치에 있는지, 소비자들의 반응은 어떠한지를 한눈에 파악할 수 있는 **프리미엄 수준의 대시보드** 완성.
